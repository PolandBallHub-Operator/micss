star 主な特徴

bolt ビルド不要・即時利用

npm, Webpack, Vite などの環境構築は一切不要。<script> タグを追加するだけで利用を開始できます。

extension Shadow DOM カプセル化

Custom Elements と Shadow DOM を採用しており、ページの既存スタイルと干渉せずに独立した UI を提供します。
